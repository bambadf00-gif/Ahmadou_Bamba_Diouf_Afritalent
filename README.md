# AfriTalent

## Présentation du projet

AfriTalent est un site vitrine fictif conçu pour mettre en relation des freelances tech africains et des entreprises à la recherche de talents. Le site présente la plateforme, ses services, ses tarifs, des profils de freelances, une page à propos et une page contact.  
Le projet a été réalisé dans le cadre du Semestre 2, avec une attention particulière portée au responsive design, à l’accessibilité et à l’interactivité.  
L’objectif est de proposer une interface moderne, claire et professionnelle inspirée des tendances web 2026.

## Fonctionnalités principales

- Navigation responsive avec barre fixe
- Mode sombre / mode clair avec sauvegarde dans `localStorage`
- Compteurs animés au scroll
- Sections avec animation fade-in
- Filtrage dynamique des freelances
- Validation JavaScript du formulaire de contact
- Carousel Bootstrap pour les témoignages
- FAQ en accordion Bootstrap
- Bouton “Retour en haut”
- Design responsive pour mobile, tablette et desktop
